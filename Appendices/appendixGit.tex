\noindent The following folder inventory describes the contents of the repository
as they existed at commit \texttt{8435c9b}. All paths are relative to the
\texttt{JupyterLab/} subfolder, which is the root of the analysis code within
the repository.

\vspace{0.5em}

\begin{itemize}
    \item \texttt{BfieldSIM/} -- Solenoid field simulation and gaussmeter mapping
    notebooks. Produces Figures~\ref{fig:Bz_vs_zSet} on simulation, and~\ref{fig:bfield_time_z} and \ref{fig:gradb_pair} for mapping.

    \item \texttt{Translational/} -- Laboratory translational force experiment.
    Susceptibility fitting and tan(alpha) vs B times grad B analysis. Produces
    Figure~\ref{fig:fit}. Includes the STL file for the 3D-printed test object
    basket (Figure~\ref{fig:leadHolder}).

    \item \texttt{Torque/Calibration/} -- Torque sensor fabrication and calibration
    data. Results appear in Figure~\ref{fig:bestRod} and
    Appendix~\ref{app:addRes_senCal}.

    \item \texttt{Torque/MRIForces/} -- Laboratory torque measurements under
    Helmholtz coil and neodymium magnet fields. Produces
    Figures~\ref{fig:torque_longerRod} and~\ref{fig:torque_shorterRod}.

    \item \texttt{ClinicalData/MappingBField/} -- Clinical magnetic field mapping
    pipeline for all fixture coordinates. Produces
    Figures~\ref{fig:G6_SEP}  and
    Appendix~\ref{app:addRes_map}.

    \item \texttt{ClinicalData/TranslationalExperiment/} -- ASTM F2052-15 pendulum
    deflection protocol applied to the epicardial lead and reference samples.
    Produces Figures~\ref{fig:F2052_FR_vs_position} and~\ref{fig:F2052_max_parison}.

    \item \texttt{ClinicalData/} root -- Cross-analysis notebook linking field
    mapping and translational results. Produces Figures~\ref{fig:comparison_gradient}
    and~\ref{fig:comparison_ordinate}.

    \item \texttt{SmallestTorquecalcs.xlsx} -- Spreadsheet for the sample
    calculations in Appendix~\ref{app:smallestTorque}.
\end{itemize}
